# Inglés con Sara — 50 lecciones

Material organizado en 50 archivos JSON para el proyecto de inglés.

- Cada archivo contiene el tema, objetivo, vocabulario, frase principal, traducción, guion por escenas, diálogo y ejercicios.
- Las lecciones 4, 8, 12, 16, 20, 24, 28, 32, 36, 40, 44 y 48 son especiales de oraciones fáciles.
- Duración objetivo: 8–9 minutos. Para conseguirla en el render, respetar pausas, repeticiones y velocidad de narración; medir la duración final con el motor de voz.
